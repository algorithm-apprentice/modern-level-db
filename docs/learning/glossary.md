# Glossary

[Learning path](README.md)

Definitions are specific to this engine where contracts vary among storage
systems.

| Term | Meaning | Lesson |
|---|---|---|
| Acquire/release | Atomic ordering that lets a reader observe initialization before a published link | [08](08-cpp-ownership-errors-and-concurrency.md) |
| Arena | Block-owning allocator with stable addresses and bulk reclamation | [03](03-memory-and-mvcc.md) |
| Atomic write batch | Ordered updates published together at one completed sequence boundary; not a read/write transaction | [03](03-memory-and-mvcc.md), [07](07-writes-and-compaction.md) |
| Background debt | Flush/compaction work still outstanding after acknowledged foreground operations | [07](07-writes-and-compaction.md), [09](09-verification-and-performance.md) |
| Block cache | Cache of independently owned decoded data blocks | [05](05-tables-filters-and-caches.md) |
| Block handle | Encoded offset and stored-block size, excluding its trailer | [05](05-tables-filters-and-caches.md) |
| Bloom filter | Probabilistic absence test: false positives are allowed, false negatives are not under valid matching semantics | [05](05-tables-filters-and-caches.md) |
| Borrowed view | Non-owning pointer/length whose validity depends on another object's lifetime and mutation | [02](02-bytes-and-formats.md), [08](08-cpp-ownership-errors-and-concurrency.md) |
| Comparator | The stable ordering/equality contract used by keys, routing, and level topology | [02](02-bytes-and-formats.md) |
| Compaction | Merge selected persistent files and install an equivalent retained logical history | [07](07-writes-and-compaction.md) |
| CRC32C | Non-cryptographic checksum used to detect accidental WAL/block corruption | [02](02-bytes-and-formats.md) |
| CURRENT | Small file naming the authoritative MANIFEST | [04](04-wal-and-recovery.md) |
| Differential test | Apply comparable operations to implementations and compare against an independent oracle | [09](09-verification-and-performance.md) |
| Directory sync | Durability operation for file/directory namespace changes, distinct from file-content sync | [04](04-wal-and-recovery.md) |
| Flush | In the engine, turn an immutable memtable into a table; in WritableFile, drain application buffering | [04](04-wal-and-recovery.md), [07](07-writes-and-compaction.md) |
| Golden vector | Independently established expected bytes, not output generated by the encoder being tested | [02](02-bytes-and-formats.md), [09](09-verification-and-performance.md) |
| Grandparent | File in the level two steps below a compaction's source level, used to constrain overlap | [07](07-writes-and-compaction.md) |
| Group commit | Queue leader commits several compatible callers with one grouped WAL operation | [07](07-writes-and-compaction.md) |
| Immutable memtable | Former mutable memtable waiting to be durably installed as a table | [03](03-memory-and-mvcc.md), [07](07-writes-and-compaction.md) |
| Internal key | User key followed by an eight-byte sequence/kind trailer | [02](02-bytes-and-formats.md) |
| L0 | Level zero: tables may overlap and reads search candidate files newest first | [06](06-reads-and-iterators.md) |
| LRU | Least-recently-used eviction policy among entries eligible for eviction | [05](05-tables-filters-and-caches.md) |
| LSM tree | Storage model combining logged writes, ordered memory state, immutable tables, and background merging | [01](01-the-engine-map.md) |
| MANIFEST | WAL-framed metadata edits identifying live tables, counters, and related state | [04](04-wal-and-recovery.md) |
| Memtable | Arena-backed ordered index of internal entries in memory | [03](03-memory-and-mvcc.md) |
| mmap | Kernel-backed file mapping; avoids some copying but can fault on storage access | [05](05-tables-filters-and-caches.md) |
| MVCC | Multi-version concurrency control: readers select history through a visibility boundary | [03](03-memory-and-mvcc.md) |
| Pin | Retention preventing a source/cache value from being reclaimed during use | [05](05-tables-filters-and-caches.md), [08](08-cpp-ownership-errors-and-concurrency.md) |
| RAII | Resource lifetime tied to an owner whose destructor performs cleanup | [08](08-cpp-ownership-errors-and-concurrency.md) |
| Read amplification | Additional source/block work required to answer reads | [01](01-the-engine-map.md) |
| Restart point | Block position with a full key that starts independent prefix reconstruction | [05](05-tables-filters-and-caches.md) |
| Sequence number | Monotonic operation-order number; not wall-clock time | [03](03-memory-and-mvcc.md) |
| Skip list | Ordered linked index with randomized shortcut levels | [03](03-memory-and-mvcc.md) |
| Snapshot | Registered visible sequence, not a copied database or independent read-only database instance | [03](03-memory-and-mvcc.md) |
| Space amplification | Storage retained beyond current live logical data | [01](01-the-engine-map.md) |
| SSTable | Immutable sorted table file containing data blocks and lookup metadata | [05](05-tables-filters-and-caches.md) |
| Sticky error | First uncertain mutation/background failure retained to prevent unsafe later progress | [04](04-wal-and-recovery.md), [07](07-writes-and-compaction.md) |
| Table cache | Cache of open table objects and their file/index/filter resources | [05](05-tables-filters-and-caches.md) |
| Tombstone | Deletion entry that hides older values until safe reclamation | [03](03-memory-and-mvcc.md), [07](07-writes-and-compaction.md) |
| Trivial move | Compaction that changes a file's level through metadata without rewriting it | [07](07-writes-and-compaction.md) |
| Trusted path | Internal operation relying on a specific established validity/lifetime invariant | [02](02-bytes-and-formats.md), [08](08-cpp-ownership-errors-and-concurrency.md) |
| Varint | Integer encoding using seven payload bits per byte and a continuation bit | [02](02-bytes-and-formats.md) |
| Version | Immutable topology of live table files; not a snapshot sequence | [01](01-the-engine-map.md) |
| VersionEdit | Encoded metadata delta applied to construct/install a Version | [04](04-wal-and-recovery.md) |
| Visibility | Whether a read's sequence and sources expose an entry, distinct from durability | [03](03-memory-and-mvcc.md), [04](04-wal-and-recovery.md) |
| WAL | Write-ahead log carrying framed logical records for replay | [04](04-wal-and-recovery.md) |
| Write amplification | Physical bytes written per logical update byte under an explicit accounting boundary | [01](01-the-engine-map.md), [09](09-verification-and-performance.md) |
